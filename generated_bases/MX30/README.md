`A30` IBP family.

- LiteRed basis files are now generated for the six `MX30` topologies;
- the package-side `MX30` cut structure and topology-denominator family are
  encoded in `src/integration_ibp.wl`;
- the public integration route is expected to stop before basis loading;
- this directory exists so the future basis-generation milestone has a stable
  package-owned location.

Intended scope:

- massive `Q Qbar g` final-final phase-space reduction;
- reduction-only milestone first;
