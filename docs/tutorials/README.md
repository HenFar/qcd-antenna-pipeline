# AntCalc tutorials

[Documentation home](../README.md) · [Manual](../manual/index.md) · [Reference guide](../reference/README.md)

These runnable, narrative notebooks are distinct from compact executable
examples: a tutorial explains a complete task, while an example demonstrates
and tests one focused call pattern.

- [Launching AntCalc](t1-launchingAntCalc.nb) installs or updates the paclet
  and loads it with `<< AntCalc\``.
- [Building A30](t2-buildingA30.nb) constructs the massless tree antenna and
  inspects its public components and intermediate stages.
- [Integrating A30](t3-integratingA30.nb) integrates the antenna, inspects the
  runtime master combination, and validates the supported target.
